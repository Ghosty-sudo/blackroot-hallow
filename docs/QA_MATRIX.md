# QA Matrix

## Automated/static
- Project expected files exist.
- Version values remain synchronized.
- No TODO/FIXME markers in release branch except explicitly waived items.
- Save schema includes version.

## Functional
- Fresh launch reaches title.
- Keyboard and controller can start and play.
- Fullscreen/windowed settings persist.
- Volume persists.
- Pause/resume cannot duplicate enemies or progression.
- Death banks only intended currency and returns cleanly.
- Boss clear advances depth once.
- Final clear increments wins once.
- Closing/reopening preserves meta progression.

## Release sessions
- First 5 minutes onboarding.
- 30 minute pacing/readability.
- Full first clear.
- 2-hour stress session.
- Fresh install.
- Existing-save upgrade.
- 720p/1080p/1440p/4K.
- Common 16:9 plus 16:10 and ultrawide presentation.
- Keyboard-only.
- Xbox-layout controller.
- Controller disconnect/reconnect.
- Low-volume/muted play.
